- **所见即所得编辑器**：控件库拖拽落点、网格吸附、对齐辅助线、实时冲突检测（重复键/保留键/区域重叠）、撤销重做、16:9/19.5:9/20:9 比例模拟、冻结帧取点、一键试玩
- **相对坐标 0~1**：同一份键位在 720P/1080P/2K 设备上都不跑偏；JSON 一键导入导出，社区自由分享
- **内置预设**：和平精英 / 王者荣耀 / 原神 / 使命召唤手游四套标准布局
- **交互细节**：`~` 一键切换映射/普通触控、Alt+Tab 失焦自动归位全部手指（防摇杆卡死）、键鼠操作实时驱动投屏演示
- **零依赖承诺**：无账号、无广告、无埋点、无云端中转；Apache-2.0 完全开源

### 快速上手 / Quick Start

1. 数据线连接手机（必须支持数据传输，优先 USB 3.0 口）
2. 手机开 USB 调试（设置 → 关于手机 → 连点版本号 7 次 → 开发者选项）
3. 授权框勾选「一律允许」
4. 选画质档位 → 预设库一键套用键位 → 按 `~` 开玩
